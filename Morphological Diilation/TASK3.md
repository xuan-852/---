# 任务三：区域膨胀算法

## 1. 处理管线

程序将二值图像表示为 `.` 和 `#`，其中 `#` 是前景。处理过程分为三层：

1. `Image` 负责图像数据、输入校验和输出。
2. `StructuringElement` 只负责保存结构元素相对于中心点的有效偏移量。
3. `dilate` 和 `erode` 接收图像与结构元素，返回新的图像，不直接修改输入。

因此，算法本身不依赖固定的结构元素，替换结构元素只需要替换对象。

## 2. 膨胀

对于输入中的每一个前景像素，将结构元素的每一个有效位置映射到该像素周围；只要结构元素覆盖到某个位置，该位置就成为前景。

5×5方形结构元素为：

```text
11111
11111
11111
11111
11111
```

它对应图中的 `dilation1`：方形边缘保持直角。

## 3. dilation2：圆角膨胀

图中的 `dilation2`具有圆角，不能继续使用全为1的方形结构元素；应改用圆形结构元素。代码使用半径为2的离散圆：

```text
00100
01110
11111
01110
00100
```

结构元素中的 `1` 表示参与膨胀的位置，`0` 表示不参与。对正方形目标进行膨胀时，圆形结构元素相当于用一个小圆沿目标边界移动，因此直边保留、四角变圆。

如果需要更精确地匹配图片，可以直接用 `StructuringElement::from_mask()` 传入新的奇数阶掩码，而不需要修改膨胀算法。

## 4. 腐蚀

腐蚀与膨胀使用相同的结构元素，但判断条件相反：只有当结构元素的所有有效位置都落在输入前景内时，输出中心位置才保留为前景；图像外部按背景处理。

腐蚀会缩小前景区域、去除细小突出部分，并可能消除小于结构元素的目标。

## 5. 与视频算法的关系

当前提交材料中没有包含视频链接或视频文件，因此这里先记录可由代码验证的共同点：视频中的滑动窗口/邻域判断算法，与本任务的形态学操作本质上都在遍历图像邻域；膨胀使用“邻域存在前景即输出前景”的逻辑，腐蚀使用“邻域全部为前景才输出前景”的逻辑。若视频还介绍了卷积或模板匹配，它们与这里共享窗口遍历形式，但判断规则和输出含义不同，不能直接把卷积结果当作形态学结果。
